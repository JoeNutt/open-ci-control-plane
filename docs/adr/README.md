# Decision records

The specification is a **baseline**. It was signed off, and it is not edited afterwards —
a design document that gets rewritten after approval is not something an implementation can
be checked against.

Anything decided after sign-off is recorded here instead, as a numbered record against that
baseline. Each one names the section of the specification it diverges from, so the pair can
be read together.
